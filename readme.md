# Ines Élégance Landing Page ✨
  
Live Demo: https://ines-elegance.netlify.app/
  
This project is a **link-in-bio style landing page** created for a business to showcase its social media presence in a clean and professional way.
  
# Features
  
- Elegant glassmorphism card design
- Luxury brown & gold color palette
- Responsive (mobile-friendly)
- Smooth hover effects & transitions
- SVG icons integration
- Clean and minimal UI

# Built with
  
- HTML5
- CSS3
